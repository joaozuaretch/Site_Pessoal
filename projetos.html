Visualizador de Funções

● Em desenvolvimento

Aplicação web interativa para visualização de funções reais e complexas, com suporte a transformações e animações em tempo real. O projeto utiliza WebGL para renderização de alta performance e permite ao usuário explorar funções matemáticas de maneira intuitiva.

Inspirado pela necessidade de ferramentas visuais melhores durante as aulas de Análise Complexa, o visualizador permite ver mapeamentos conformes, transformações de Möbius e superfícies de Riemann em 3D interativo.

Crivo de Eratóstenes Otimizado

● Concluído

Implementação em C++ de múltiplos algoritmos para geração e teste de números primos, incluindo o Crivo de Eratóstenes clássico, Crivo de Atkin e Crivo Segmentado. O projeto inclui análise detalhada de complexidade computacional e benchmarks comparativos.

Desenvolvido como parte da iniciação científica em Teoria dos Números, o projeto demonstra como otimizações algorítmicas podem reduzir drasticamente o tempo de computação para encontrar primos em intervalos grandes (até 10⁹).

3 algoritmos implementados Benchmarks automáticos Análise de complexidade O(n log log n) Otimização com bit manipulation Testes unitários com Google Test Documentação com Doxygen
C++ Algoritmos Teoria dos Números CMake

Simulador de Séries Numéricas

● Concluído

Ferramenta educacional interativa que ilustra convergência e divergência de séries infinitas com gráficos animados e testes interativos. Projetada para auxiliar estudantes de Cálculo e Análise Real a desenvolverem intuição sobre séries.

O simulador permite ao estudante selecionar diferentes séries (geométrica, harmônica, p-séries, séries de potências) e observar visualmente o comportamento das somas parciais, aplicando critérios de convergência como o teste da razão, teste da raiz e teste integral.

Visualização animada de somas parciais 10+ séries pré-configuradas Testes de convergência interativos Notebooks Jupyter documentados
Python Matplotlib Jupyter ipywidgets

Resolução de EDOs com Runge-Kutta

● Em desenvolvimento

Biblioteca Python para resolução numérica de equações diferenciais ordinárias usando métodos de Runge-Kutta de 1ª a 4ª ordem. Inclui comparação visual entre diferentes ordens de aproximação e análise de erro com soluções exatas conhecidas.

Desenvolvido como projeto do curso de extensão do IMPA, a biblioteca oferece uma API simples e documentada, com gráficos comparativos automáticos e suporte a sistemas de EDOs.

Métodos RK1 a RK4 Suporte a sistemas de EDOs Análise de erro automática Gráficos comparativos Documentação Sphinx Testes com pytest
Python SciPy EDO Matplotlib

Visualizador de Séries de Fourier

● Concluído

Aplicação web que demonstra a decomposição de funções periódicas em séries de Fourier. O usuário pode desenhar uma forma de onda arbitrária e observar como os harmônicos individuais se combinam para aproximá-la.

Projeto apresentado no Congresso Nacional de Matemática Aplicada, demonstrando a convergência das somas parciais de Fourier e fenômenos como o efeito Gibbs em descontinuidades.

Desenho de formas de onda Visualização de harmônicos Demonstração do efeito Gibbs Animação em tempo real
JavaScript Canvas API Web Audio API
